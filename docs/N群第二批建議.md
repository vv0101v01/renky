## 二、盤點發現的三個結構性問題

這三點會決定第二批怎麼排，比「再加幾條律」重要。

### 2.1 ⚠️ ℝ 軌沒有成本計量器 —— 這是最大的阻塞

專案裡**最昂貴、最值得套結構律的演算法全在 ℝ 軌**，而它們完全沒有成本插裝：

| 演算法 | 型別 | 成本 | 現有計量 |
| --- | --- | --- | :-: |
| `jacobi_eigen` | `RMat → (Array[Double], RMat)` | 迭代 O(sweeps·n³) | **無** |
| `svd_jacobi` | `RMat → (RMat, Array[Double], RMat)` | 迭代，最貴 | **無** |
| `ldlt` / `sqrtm_spd` / `polar_decomposition` | `RMat` | O(n³) | **無** |
| `pinv` / `cond2` / `expm` | `RMat` | O(n³)〜 | **無** |

`Cost` 結構只有 `wmul / wadd / bigops / maxbits`，全部繫於 BigInt 字乘 ——
對 `Double` 毫無意義。所以目前 N 群只能在 ℚ 軌玩，而 ℚ 軌的 Φ
（det/inv/rank/trace/adj）**恰好是最便宜的那些**。

> **這解釋了一個尷尬事實**：N-13 搜尋到的最大增益是 ×6.33，
> 而真正該有 ×200 的 `eig(A⊗B) = spec A × spec B` 根本進不了搜尋空間。

### 2.2 `check_law` 不對組合子 C(A,B) 計費

`check_law` 裡 `direct(comb(a,b), cd)` 的 `comb` 在 Cost 之外，
等於**白送直接法一個已組好的大矩陣**。

- 對 ⊗ 的 inv/det 律：低估了增益（偏保守，安全）。
- 對 transpose：直接法得 0 次乘法，產生 ×0.00 的假象 —— 我已在 N-13 標為「未計量」，但根因沒修。

N-11 的 `synth_compare` 用 `sgram_cost` 誠實計費，兩者標準不一致。**應統一。**

### 2.3 外冪沒有複合矩陣

Sylvester–Franke 需要複合矩陣 `Cₖ(A)`（元素為 A 的 k×k 子式）。
零件齊全（`subsets_k`、`merge_sign`、`binom`、`subset_index_table`），
但**沒有組裝出 `Cₖ(A)` 的函式**。N-10 要先補這個。

## 三、第二批提案

### A 組：ℚ 軌補完（低風險，可立即動工）

#### ⭐ N-10 外冪律 Sylvester–Franke —— 全專案預期增益最大

```
det(Cₖ(A)) = det(A)^C(n−1, k−1)          Cₖ(A) 為 A 之第 k 複合矩陣（C(n,k) 階）
G(Λᵏ V)   = Cₖ(G(V))                     外冪空間之 Gram 即複合矩陣
```

成本試算（直接法須先物化 `Cₖ(A)`，這點必須誠實計入）：

| n, k | C(n,k) | 直接（建表 + 消去） | 分解（n 階 det + 冪） | 增益 |
| --- | --- | --- | --- | --- |
| 6, 3 | 20 | 10,800 + 8,000 | ~216 | **×88** |
| 8, 4 | 70 | 313,600 + 343,000 | ~512 | **×1,280** |
| 10, 5 | 252 | 7.9M + 16M | ~1,000 | **×24,000** |

> 義務建議取 n = 5,6,7（基準跑得動），n = 8 以上列為一次性實測並註明。
> 這會是目前唯一一條增益破 10³ 的結構律。

**附帶收穫**：`Cₖ(A)` 一旦存在，`exterior_power_space` 就能接上 N-01 的
表達式樹（新增 `SExt(e, k)` 節點），且外冪是**第一個會讓 N-12 分派器
真的選「攤平」的節點**（k 接近 n/2 時 C(n,k) 爆炸，分解反而不划算）。

#### N-06 Hom 律 —— 雙重分解，現成零件最多

```
Hom(V,W) ≅ W ⊗ V*        ⇒   G(Hom) = G(W) ⊗ G(V)⁻ᵀ
                         ⇒   inv G(Hom) = inv G(W) ⊗ G(V)       ← 對偶節點零成本
```

這是 N-03 ∘ N-05 的複合，預期是**單節點增益最高者**（⊗ 的 Θ(n³) 省下
再疊上 * 的零成本）。`hom_space` 已存在，F-05 已驗證同構。
加 `SHom` 節點後立刻與 catamorphism 相容。
**工作量最小、收益明確 —— 建議作為第二批第一條動工。**

#### N-08 + N-09 同餘律族（度量扭曲 + 子空間）—— 新的「律的種類」

```
G_A = AᵀGA        inv(AᵀGA) = A⁻¹ G⁻¹ A⁻ᵀ        det(AᵀGA) = det(A)²·det(G)
子空間：G_U = SᵀGS（S 為含入映射，非方陣）；G_U 正定 ⟺ S 單射
```

**成本面大概率是 ×1 的誠實負面結果**（A 稠密時分解不比直接便宜），
但它帶來一個**新的律種類**：**Sylvester 慣性律**

```
inertia(AᵀGA) = inertia(G)        A 非奇異
```

這是**不變量律**而非加速律 —— 回報的不是「快多少」而是「什麼被保持」。
現在 `LawVerdict` 只有 `holds + 成本比`，要加一個 verdict 種類。
這會讓 N-02 的檢驗器從「加速律檢驗器」升級成「結構律檢驗器」。
`inertia` 與 `gram_change_of_basis` 都已存在。

#### N-07 實化律（ℂ→ℝ）

```
G_ℝ = [[Re G, −Im G], [Im G, Re G]]      det_ℝ = |det_ℂ|²      譜倍增
```
`realify` 已存在、`Cpx[F]` 已存在。中等風險：需要 ℚ(i) 的 Gram。

#### N-14 反律庫（獨立登錄）

目前反例散落 6 處（N-04 ⊕ ×1.1、N-12 Hadamard 慘敗、N-13 的 29 條推翻、
M-08 積樹、L-05 ×0.15、L-08 ×0.6）。建議做成單一可查詢登錄表，
義務斷言「每筆都附具體反例或實測比值」。**成本低、誠信價值高。**

### B 組：ℝ 軌開通（需先造計量器，但這裡才有大魚）

#### ⭐⭐ N-20 flop 計量器 —— 阻塞解除件，建議優先於 B 組其餘各條

為 `Cost` 加 `flops` 欄並插裝 RMat 基本運算（或做計數包裝層）。
沒有它，下面四條全部只能靠掛鐘時間，違背本專案
「確定性成本模型、與平台無關、可重現可審計」的既定紀律。

順帶把 §2.2 的 `check_law` 計費不一致一起修掉。

#### ⭐⭐ N-21 譜律族 —— 實際增益可能超過 N-10

```
spec(A⊗B) = {λᵢ·μⱼ}        spec(A⊕B) = spec A ⊎ spec B
ρ(A⊗B) = ρ(A)·ρ(B)         κ₂(A⊗B) = κ₂(A)·κ₂(B)
特徵向量：v_i ⊗ w_j
```

Jacobi 特徵分解是**迭代**的（sweeps × n³），dim 64 直接做 vs 兩個 dim 8：
`10·64³ = 2.6M` vs `2·10·8³ = 10K` ＋ 組裝 4096 → **約 ×200**。

> 比 Sylvester–Franke 更實用：N-10 的 ×10⁴ 建立在「直接法笨到去物化 252 階矩陣」
> 之上，而 N-21 的 ×200 是對一個**本來就很貴且天天在用**的演算法的真實加速。
> `jacobi_eigen`、`cond2`、`spectral_radius_sym` 皆已存在。

#### N-22 分解律族

```
chol(A⊗B) = chol(A) ⊗ chol(B)          LDLᵀ 同理
QR(A⊗B)   = (Q_A⊗Q_B)(R_A⊗R_B)
SVD(A⊗B)  = (U_A⊗U_B)(Σ_A⊗Σ_B)(V_A⊗V_B)ᵀ
polar(A⊗B) = (U_A⊗U_B)(P_A⊗P_B)
```
SVD 經 Jacobi 實作最貴 ⇒ 增益最高。`ldlt`、`svd_jacobi`、`polar_decomposition`、
`householder`、`gram_schmidt`、`modified_gram_schmidt` 全部現成。

#### N-23 投影／偽逆律

```
pinv(A⊗B) = pinv(A) ⊗ pinv(B)          P_{V⊗W} = P_V ⊗ P_W
```
`pinv`、`projection_matrix`、`project_onto`、`orthogonal_complement` 現成。

#### N-24 矩陣函數律（含 Kronecker 和）

```
expm(A⊕B) = expm(A) ⊕ expm(B)
expm(A⊗I + I⊗B) = expm(A) ⊗ expm(B)        ← Lie 積律，Kronecker 和
sqrtm(A⊗B) = sqrtm(A) ⊗ sqrtm(B)
```
第二式特別好：**Kronecker 和是個新的組合子**，不是 ⊗ 也不是 ⊕。
`expm`、`sqrtm_spd` 現成。

### C 組：回頭收割 —— 把既有演算法重新解釋為 N 群實例

#### ⭐ N-25 快速變換即結構律（觀念收益最大的一條）

```
H_{2ᵏ} = H_2 ⊗ H_{2ᵏ⁻¹}                       Sylvester–Hadamard 構造
FWHT   = 依序套用 (I ⊗ H₂ ⊗ I) 各因子           ← 這就是 Kronecker 樹上的 catamorphism
DFT_{nm} = P (DFT_n ⊗ I_m) T (I_n ⊗ DFT_m) Q    Cooley–Tukey
```

主張：**本庫既有的 `fft` / `fwht` / `hadamard_matrix` 並不是獨立演算法，
而是 N-11 catamorphism 在 Kronecker 樹上的實例**；它們的
Θ(n log n) vs Θ(n²) 加速**就是**結構律增益。

可驗證形式：令合成器對 Kronecker 樹產生變換演算法，
斷言其輸出與既有 `fft`／`fwht` **逐元素相同**，且成本比等於既知的 n/log n。

> 這條不新增演算法能力，但**把 H 群的幾條數值演算法回收為 N 群實例** ——
> 等於用生成器解釋了庫裡本來就有的東西，是對「生成器是真的」最強的證據。
> `fft`、`fwht`、`hadamard_matrix`、`haar_matrix`、`dft_matrix` 全部現成。

#### N-26 擴編搜尋空間

N-13 現為 7 Φ × 2 C × 3 ⊙ = 42。補上 Φ {charpoly, pinv, chol, eig, Λᵏ}
與 C {Hom, *, 同餘, Λᵏ, Kronecker 和} 後約 **250–300 候選**，
逼近原規劃的 161 並超出。

> 風險：候選數 ×7，執行時間會線性上升。現在 N-13 佔 462 ms，
> 擴編後約 3 s —— 已逼近全庫 5.34 s 的量級。
> **建議搜尋引擎改為「分層」：常規義務跑小網格精簡候選集，
> 全量搜尋移到 `cmd/lawsearch/` 獨立執行檔，結果落檔到 docs。**

## 四、建議動工順序

| 序 | 條目 | 理由 | 風險 |
| :-: | --- | --- | :-: |
| 1 | **N-06 Hom 律** | 零件最齊、與 catamorphism 立即相容、增益明確 | 低 |
| 2 | **N-20 flop 計量器** | 阻塞解除件；順手修 `check_law` 計費不一致 | 低 |
| 3 | **N-21 譜律族** | 計量器一通就能收的最大實用增益（×200） | 中 |
| 4 | **N-10 Sylvester–Franke** | 預期 ×10⁴；需先造 `Cₖ(A)`；會首次觸發分派器選「攤平」 | 中 |
| 5 | **N-25 快速變換即結構律** | 觀念收益最大；回收 H 群 | 中 |
| 6 | N-22 / N-23 / N-24 | 計量器就緒後成批量產 | 低 |
| 7 | N-08+N-09 同餘律族 | 引入「不變量律」新種類，需擴 `LawVerdict` | 中 |
| 8 | N-14 反律庫 | 便宜，誠信價值高，可隨時插隊 | 低 |
| 9 | N-07 實化律 | 需 ℚ(i) Gram | 中 |

而且它打中的是**本來就貴、本來就常用**的演算法，不是為了演示而造的場景。
