## 4. E0073 與 E0084 之張力：寫法定案

此工具鏈同時提供兩條方向相反的提示，當 `let` **已給型別標註**時兩者互斥：

| 寫法 | E0084 `unqualified_record` | E0073 `unnecessary_annotation` |
| --- | --- | --- |
| `let vs : T = { … }` | ✗ 嫌缺前綴 | ✓ |
| `let vs : T = T::{ … }` | ✓ | ✗ 嫌前綴多餘 |
| **`let vs = T::{ … }`（定案）** | **✓** | **✓** |

定案取第三列：**以 `T::{ … }` 前綴承擔型別資訊，不再重複 `let` 的型別標註**。
泛型之型別引數由上下文（函式回傳型別、後續使用）推得，實測 23 處全部通過型別檢查。
兩條提示因此**同時成立**，`moon.mod` 可將六類選擇性警告全部常開：

```toml
warnings = "+missing_doc+unqualified_record+prefer_readonly_array+missing_invariant+missing_reasoning+unnecessary_annotation"
```

而最強閘門 `moon check --target all --warn-list "+all" --deny-warn` 亦為**零警告**。

## 6. 一處「刻意不做」的決定

**`oblig_auto.mbt` 不格式化**。該檔由 `moon run cmd/genoblig` 產生，
其逐位元組可重現性是 N-45 之義務（`genoblig | diff - oblig_auto.mbt` 必須為空）。
`moon fmt` 會重排其 `match`／`if` 排版，一旦格式化即破壞此閘門，故留原樣
（本次曾誤格式化後已還原，並複驗 diff 為空）。
若要連它都 fmt 乾淨，正解是**讓生成器輸出 moon fmt 之正則形式**（見建議書 §3）。
