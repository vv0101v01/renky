## 一、設計原則與證明方法論

### 1.1 零第三方依賴

`moon.mod` 之依賴區為空，函式庫本體之 import 區亦為空；連 `@math` 亦未使用 —— `sqrt`／`sin`／`cos`／`atan2`／`exp` 全部自行以 Newton 迭代與 Taylor 級數實作（kernel.mbt），有理數、複數、四元數之算術亦全部自建。

### 1.2 兩條算術軌道

| 軌道 | 純量體 | 判等 | 證明形態 |
| --- | --- | --- | --- |
| 精確軌道 | ℚ（BigInt 既約分數）、ℚ(i)、ℚ 上之四元數 | 結構相等（無誤差） | 代數恆等式於隨機實例上**精確**成立 |
| 數值軌道 | Double | 相對 ε = 10⁻⁹ | 事後殘差憑證 ‖R(X̂)‖ ≤ ε（後向穩定性） |

### 1.3 「義務自證」之形式化地位

每條準則都附一個可執行之 *proof obligation*。於精確軌道上，公理與恆等式皆為座標與純量之多項式映射（次數 ≤ 2 或 ≤ 3）。若某恆等式不成立，其差為非零多項式 P；於取樣集 S ⊂ ℚ（|S| ≥ 52 個小有理數）隨機取值時，由 **Schwartz–Zippel 引理**：

> Pr[P(ξ) = 0] ≤ deg P / |S| ≤ 2/52 < 0.04，

故 t 次獨立實例全通過而命題為假之機率 ≤ 0.04^t（t = 24 時 < 10⁻³⁴）。於數值軌道上，我們不宣稱 X̂ = X，而是驗證可機器檢查之殘差不等式，配合後向穩定性定理即得「X̂ 為一個近鄰問題之精確解」。

此外，每一條目之原始碼區塊註解中載有**定義／命題／定理／證明**（紙上證明），報告之對應欄位為其摘要；程式只負責把「證明之可檢查推論」逐例驗證，兩者互補。

## 四、逐條詳述（定義 · 算式 · 命題／定理 · 證明 · 義務自證）

### A 群 · 體、純量與核心工具

#### A-01　確定性偽亂數產生器 xorshift64*

- **類別**：核心工具　　**適用空間**：所有空間之取樣　　**軌道**：位元精確
- **定義**：狀態 s ∈ ℤ₂⁶⁴＼{0}，s ← s⊕(s≫12)，s ← s⊕(s≪25)，s ← s⊕(s≫27)，輸出 s·2685821657736338717。
- **算式**：x_{k+1} = T(x_k)，T 為 GF(2) 上之可逆線性變換再乘上奇數常數
- **命題／定理**：命題：T 於 ℤ₂⁶⁴＼{0} 上為雙射，故序列不會落入 0；同種子產生相同序列（確定性可重現）。
- **證明**：三個 xorshift 皆為 GF(2)⁶⁴ 上之單位三角矩陣（對角為 1）故可逆；乘以奇數為 ℤ/2⁶⁴ 中之單位元，亦可逆。可逆變換之複合保持非零性。∎
- **義務自證**：✔ 通過　（實例數 2000）　同種子序列相同；輸出非零；8 桶皆有樣本

#### A-02　Euclid 最大公因數（BigInt）

- **類別**：核心工具　　**適用空間**：ℚ 之正規化　　**軌道**：精確 ℤ
- **定義**：gcd(a,0)=|a|；gcd(a,b)=gcd(b, a mod b)。
- **算式**：gcd(a,b)·lcm(a,b) = |ab|
- **命題／定理**：定理：Euclid 演算法於有限步終止並回傳最大公因數。
- **證明**：|b| 嚴格遞減且非負 ⇒ 終止；由 (a,b) 與 (b, a mod b) 之公因數集合相同（因 a = qb + r）得正確性。∎
- **義務自證**：✔ 通過　（實例數 200）　g | a, g | b, gcd·lcm = |ab|

#### A-03　有理數體 ℚ（既約表示）

- **類別**：純量體　　**適用空間**：全部精確軌道空間　　**軌道**：精確 ℚ
- **定義**：Q = {p/q : p,q ∈ ℤ, q > 0, gcd(p,q)=1}，加法 p₁/q₁+p₂/q₂ = (p₁q₂+p₂q₁)/(q₁q₂) 後約分。
- **算式**：(F1)–(F9)：結合、交換、分配、單位元、逆元
- **命題／定理**：定理：(ℚ,+,·) 為特徵 0 之有序體；本實作之正規化使相等判定 = 結構相等。
- **證明**：逐條驗證體公理（見 rational.mbt）；既約表示之唯一性由 gcd 與 q>0 保證，故 s_eq 可判定。∎
- **義務自證**：✔ 通過　（實例數 300）　結合/交換/分配/逆元/0≠1

#### A-04　整數平方根 ⌊√a⌋（Newton 下取整）

- **類別**：核心工具　　**適用空間**：ℚ 上之精確開方判定　　**軌道**：精確 ℤ
- **定義**：r = max{ k ∈ ℕ : k² ≤ a }。
- **算式**：r² ≤ a < (r+1)²
- **命題／定理**：命題：整數 Newton 迭代 x ← (x + a/x)/2 自 x₀ ≥ √a 起單調遞減收斂至 ⌊√a⌋。
- **證明**：AM–GM 給出 x_{k+1} ≥ √a；整數除法之下取整保證嚴格遞減直至不動點，於不動點處即滿足夾擠不等式。∎
- **義務自證**：✔ 通過　（實例數 200）　r² ≤ a < (r+1)²

#### A-05　Newton 法平方根（Double）

- **類別**：核心工具　　**適用空間**：ℝ 軌道之範數　　**軌道**：數值 ℝ
- **定義**：x_{k+1} = (x_k + a/x_k)/2，x₀ = max(1,a)。
- **算式**：|x̂² − a| ≤ 10⁻⁹·max(1,a)
- **命題／定理**：定理：Newton 迭代對 f(x)=x²−a 為二次收斂；殘差憑證可事後檢查。
- **證明**：f 於 (0,∞) 上凸且 f′>0 ⇒ 自右側起單調遞減收斂；誤差 e_{k+1} = e_k²/(2x_k)。本實作直接驗證最終殘差。∎
- **義務自證**：✔ 通過　（實例數 500）　最差相對殘差 4.175e-16

#### A-06　Taylor 級數 sin / cos（含區間歸約）

- **類別**：核心工具　　**適用空間**：DFT／旋轉角　　**軌道**：數值 ℝ
- **定義**：先將 x 歸約至 [−π,π]，再取 sin x = Σ_{k≥0} (−1)^k x^{2k+1}/(2k+1)!。
- **算式**：sin²x + cos²x = 1；sin(x+y) = sin x cos y + cos x sin y
- **命題／定理**：命題：截斷 N 項之誤差 ≤ |x|^{2N+1}/(2N+1)!；歸約後 |x| ≤ π 使誤差 < 10⁻¹⁶。
- **證明**：交錯級數餘項估計；加法定理由指數律 e^{i(x+y)} = e^{ix}e^{iy} 比較實虛部，於本實作以數值恆等式驗證。∎
- **義務自證**：✔ 通過　（實例數 400）　sin²+cos²=1、加法定理，最差 3.580e-15

#### A-07　四象限反正切 atan2

- **類別**：核心工具　　**適用空間**：夾角計算　　**軌道**：數值 ℝ
- **定義**：θ = atan2(y,x) ∈ (−π,π]，由級數 arctan + 象限修正組成。
- **算式**：r cos θ = x，r sin θ = y，r = √(x²+y²)
- **命題／定理**：命題：atan2 為極座標映射之右逆（除原點外）。
- **證明**：以 |y/x| ≤ 1 之級數加上 arctan(t)+arctan(1/t)=π/2 之恆等式延拓；象限由 x,y 之符號決定。驗證以重建 (x,y) 之殘差為憑證。∎
- **義務自證**：✔ 通過　（實例數 400）　最差偏差 7.105e-15

#### A-08　快速冪（平方–乘法）

- **類別**：核心工具　　**適用空間**：任意么半群　　**軌道**：精確 ℚ
- **定義**：a^0 = 1；a^{2k} = (a^k)²；a^{2k+1} = a·(a^k)²。
- **算式**：a^{m+n} = a^m·a^n
- **命題／定理**：命題：於任意么半群上正確，乘法次數 ≤ 2⌊log₂ n⌋。
- **證明**：對 n 之二進位長度歸納；指數律由結合律得。∎
- **義務自證**：✔ 通過　（實例數 150）　a^{m+n} = a^m a^n

#### A-09　複數體 ℚ(i)（Gauss 有理數）

- **類別**：純量體　　**適用空間**：ℂⁿ、Hermitian 空間　　**軌道**：精確 ℚ(i)
- **定義**：z = a+bi，a,b ∈ ℚ；(a+bi)(c+di) = (ac−bd)+(ad+bc)i；N(z) = a²+b²。
- **算式**：z⁻¹ = ‾z/N(z)；N(zw) = N(z)N(w)
- **命題／定理**：定理：ℚ(i) 為體；N 為乘法同態（Brahmagupta–Fibonacci 二平方恆等式）。
- **證明**：N(z) = z‾z，而共軛為環自同構 ⇒ N(zw) = zw‾z‾w = N(z)N(w)；z ≠ 0 ⇒ N(z) > 0 ⇒ 可逆。∎
- **義務自證**：✔ 通過　（實例數 200）　‾(zw)=‾z‾w，N(zw)=N(z)N(w)

#### A-10　四元數代數 ℍ（Hamilton 乘法）

- **類別**：純量代數　　**適用空間**：ℍⁿ、SO(3)　　**軌道**：精確 ℚ
- **定義**：q = w+xi+yj+zk，i²=j²=k²=ijk=−1，乘法按分配律展開。
- **算式**：(w₁,v₁)(w₂,v₂) = (w₁w₂ − ⟨v₁,v₂⟩, w₁v₂ + w₂v₁ + v₁×v₂)
- **命題／定理**：定理：ℍ 為 4 維實結合可除代數，非交換；其中心為 ℝ。
- **證明**：結合律由基元關係逐項驗證（本義務以隨機 ℚ 四元數三元組精確檢驗）；可除性由 q⁻¹ = ‾q/N(q) 與 N(q) > 0 (q≠0) 得。∎
- **義務自證**：✔ 通過　（實例數 150）　i²=j²=k²=ijk=−1，結合、分配、非交換

### C 群 · 矩陣核心演算法

#### C-01　矩陣乘法與環結構

- **類別**：矩陣演算法　　**適用空間**：M_{m×n}(𝔽)　　**軌道**：精確 ℚ

- **命題／定理**：定理：M_n(𝔽) 為含單位元之結合環；乘法對應線性映射之複合。

#### C-02　轉置與共軛轉置之反序律

- **類別**：矩陣演算法　　**適用空間**：M_{m×n}(𝔽), M(ℂ)　　**軌道**：精確 ℚ/ℚ(i)
- **定義**：(Aᵀ)_{ij} = A_{ji}；(A*)_{ij} = ‾A_{ji}。
- **算式**：(AB)ᵀ = BᵀAᵀ；(AB)* = B*A*
- **命題／定理**：命題：轉置為反自同構；共軛轉置為共軛線性反自同構。
- **證明**：((AB)ᵀ)_{ij} = Σ_k A_{jk}B_{ki} = Σ_k (Bᵀ)_{ik}(Aᵀ)_{kj}。共軛版本再用 ‾(zw)=‾z‾w。∎
- **義務自證**：✔ 通過　（實例數 40）　實與複皆驗

#### C-03　Gauss–Jordan 消去與 RREF

- **類別**：矩陣演算法　　**適用空間**：M_{m×n}(𝔽)　　**軌道**：精確 ℚ
- **定義**：以初等列運算化為列化簡階梯形 R，主元為 1 且其所在行其餘元素為 0。
- **算式**：R = EA，E 可逆；ker A = ker R；row A = row R
- **命題／定理**：定理：RREF 存在且唯一；rank = 主元數；RREF 為冪等運算。
- **證明**：三類初等列運算對應可逆矩陣；唯一性由主元位置與列空間決定。本義務驗證冪等性與零空間保持。∎
- **義務自證**：✔ 通過　（實例數 25）　RREF²=RREF，A·ker = 0

#### C-04　秩與秩–零化度定理

- **類別**：矩陣演算法　　**適用空間**：M_{m×n}(𝔽)　　**軌道**：精確 ℚ
- **定義**：rank A = RREF 之主元數；nullity = dim ker A。
- **算式**：rank A + nullity A = n；rank A = rank Aᵀ = rank AᵀA
- **命題／定理**：定理（秩–零化度）：dim im T + dim ker T = dim V。
- **證明**：自由變數對應零空間基底、主元變數對應像空間基底；rank A = rank AᵀA 因 ker A = ker AᵀA（實體上 ‖Ax‖² = xᵀAᵀAx）。∎
- **義務自證**：✔ 通過　（實例數 25）　rank + nullity = n

#### C-05　行列式（消去法／樞軸乘積）

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：det A = sign(σ)·Π 樞軸（由 LU/消去過程取得）。
- **算式**：det A = (−1)^{換列次數}·Π u_ii
- **命題／定理**：定理：行列式為交錯多線性型式，由 det I = 1 唯一決定。
- **證明**：初等列運算對行列式之作用（換列變號、倍乘按比例、加倍數不變）；上三角矩陣之行列式為對角乘積。∎
- **義務自證**：✔ 通過　（實例數 30）　兩獨立演算法交叉驗證

#### C-06　行列式（Laplace 餘因子展開）

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：det A = Σ_j (−1)^{i+j} a_{ij} M_{ij}（沿第 i 列展開）。
- **算式**：det A = Σ_{σ∈S_n} sgn(σ) Π aᵢ_{σ(i)}
- **命題／定理**：定理：Laplace 展開與消去法結果相同（兩種獨立演算法之交叉驗證）。
- **證明**：兩者皆滿足交錯多線性與 det I = 1，由唯一性定理相等。本義務以隨機 ℚ 矩陣逐例驗證。∎
- **義務自證**：✔ 通過　（實例數 30）　兩獨立演算法交叉驗證

#### C-07　行列式之乘性

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：det : M_n → 𝔽。
- **算式**：det(AB) = det A·det B；det Aᵀ = det A
- **命題／定理**：定理：det 為么半群同態 (M_n,·) → (𝔽,·)；GL_n 為其核之補。
- **證明**：固定 B，A ↦ det(AB) 為 A 之交錯多線性型式，故等於 c·det A，取 A = I 得 c = det B。∎
- **義務自證**：✔ 通過　（實例數 30）　det(AB)=detA·detB，det Aᵀ=det A

#### C-08　反矩陣（Gauss–Jordan）

- **類別**：矩陣演算法　　**適用空間**：GL_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：對 [A | I] 作 RREF，若左半為 I 則右半為 A⁻¹。
- **算式**：AA⁻¹ = A⁻¹A = I；(AB)⁻¹ = B⁻¹A⁻¹
- **命題／定理**：定理：A 可逆 ⟺ rank A = n ⟺ det A ≠ 0。
- **證明**：RREF 之可逆列運算 E 滿足 EA = I ⇒ E = A⁻¹；反序律由結合律驗證。∎
- **義務自證**：✔ 通過　（實例數 25）　AA⁻¹=I，(AB)⁻¹=B⁻¹A⁻¹

#### C-09　線性方程組與 Rouché–Capelli 定理

- **類別**：矩陣演算法　　**適用空間**：M_{m×n}(𝔽)　　**軌道**：精確 ℚ
- **定義**：msolve(A,b) 回傳 (相容性, 特解, 零空間基底)。
- **算式**：Ax = b 相容 ⟺ rank A = rank[A|b]；通解 = 特解 + ker A
- **命題／定理**：定理（Rouché–Capelli）：解集為仿射子空間，維數 = n − rank A。
- **證明**：增廣矩陣之 RREF 若出現 [0 … 0 | c], c≠0 則不相容；否則由自由變數參數化解集。∎
- **義務自證**：✔ 通過　（實例數 25）　通解 = 特解 + ker A

#### C-10　零空間與列／行空間基底

- **類別**：矩陣演算法　　**適用空間**：四基本子空間　　**軌道**：精確 ℚ
- **定義**：mnullspace／mcolspace／mrowspace 由 RREF 之自由變數與主元行構造。
- **算式**：dim ker A = n − r；dim col A = dim row A = r
- **命題／定理**：定理：四基本子空間之維數為 r, n−r, r, m−r。
- **證明**：由 RREF 之結構直接讀出；基底之線性獨立性由主元位置保證。∎
- **義務自證**：✔ 通過　（實例數 20）　row⊥ker，col⊥ker(Aᵀ)，維數 r,(n−r),(m−r)

#### C-11　四基本子空間之正交分解

- **類別**：矩陣演算法　　**適用空間**：𝔽ⁿ = row A ⊕ ker A　　**軌道**：精確 ℚ
- **定義**：row(A) ⊥ ker(A)，col(A) ⊥ ker(Aᵀ)。
- **算式**：𝔽ⁿ = row A ⊥⊕ ker A；𝔽^m = col A ⊥⊕ ker Aᵀ
- **命題／定理**：定理（線性代數基本定理）：上述兩組為正交直和分解。
- **證明**：x ∈ ker A ⟺ 每一列與 x 內積為 0 ⟺ x ⊥ row A；維數相加為 n 故為直和。∎
- **義務自證**：✔ 通過　（實例數 20）　row⊥ker，col⊥ker(Aᵀ)，維數 r,(n−r),(m−r)

#### C-12　LU 分解（部分樞軸）

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：PA = LU，L 單位下三角，U 上三角，P 為置換。
- **算式**：det A = (−1)^{swaps}·Π u_ii
- **命題／定理**：定理：任意方陣經列置換後存在 LU 分解；可逆時 L,U 唯一。
- **證明**：對行歸納消去；部分樞軸保證主元非零（若存在）。行列式公式由三角矩陣性質與置換符號得。∎
- **義務自證**：✔ 通過　（實例數 25）　並由樞軸乘積重算 det

#### C-13　Kronecker 積與混合積律

- **類別**：矩陣演算法　　**適用空間**：張量積空間　　**軌道**：精確 ℚ
- **定義**：(A⊗B)_{(i,k),(j,l)} = A_{ij}B_{kl}。
- **算式**：(A⊗B)(C⊗D) = AC⊗BD；tr(A⊗B) = trA·trB；det(A⊗B) = (detA)^{n_B}(detB)^{n_A}
- **命題／定理**：定理：⊗ 為雙線性、結合，且與乘法相容（函子性）。
- **證明**：混合積律由指標直接展開；det 公式由 A⊗B = (A⊗I)(I⊗B) 與相似變換之行列式乘性得。∎
- **義務自證**：✔ 通過　（實例數 20）　混合積律、tr、det

#### C-14　vec 運算與 Sylvester 方程之線性化

- **類別**：矩陣演算法　　**適用空間**：Hom 空間　　**軌道**：精確 ℚ
- **定義**：vec(X) 為按行堆疊（column-stacking）。
- **算式**：vec(AXB) = (Bᵀ⊗A)vec X
- **命題／定理**：定理：矩陣方程可線性化為 Kronecker 系統；unvec∘vec = id。
- **證明**：逐元素比較 (AXB)_{ij} = Σ_{k,l} A_{ik}X_{kl}B_{lj} 與 Kronecker 積之指標排列。∎
- **義務自證**：✔ 通過　（實例數 20）　並驗 unvec∘vec = id

#### C-15　Schur 補與分塊行列式

- **類別**：矩陣演算法　　**適用空間**：分塊矩陣　　**軌道**：精確 ℚ
- **定義**：M = [[A,B],[C,D]]，S = D − CA⁻¹B。
- **算式**：det M = det A · det S
- **命題／定理**：定理：A 可逆時分塊 LU 分解 M = [[I,0],[CA⁻¹,I]][[A,B],[0,S]]。
- **證明**：直接相乘驗證分解；取行列式並用三角分塊矩陣之行列式公式。∎
- **義務自證**：✔ 通過　（實例數 25）　det M = det A · det(D − CA⁻¹B)

#### C-16　Faddeev–LeVerrier 特徵多項式

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：遞推 M₀=0, M_k = A M_{k−1} + c_{n−k+1}I，c_{n−k} = −tr(A M_k)/k。
- **算式**：χ_A(λ) = det(λI − A) = λⁿ + c_{n−1}λ^{n−1} + … + c₀
- **命題／定理**：定理：c_{n−1} = −tr A，c₀ = (−1)ⁿ det A，且演算法於任意特徵 0 體上正確。
- **證明**：由 Newton 恆等式連結冪和 tr(A^k) 與初等對稱多項式（特徵值之對稱函數）。∎
- **義務自證**：✔ 通過　（實例數 20）　χ_A(A)=0，χ(0)=(−1)ⁿdetA，c_{n−1}=−trA

#### C-17　Cayley–Hamilton 定理

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：將 χ_A 之係數代入矩陣多項式。
- **算式**：χ_A(A) = 0
- **命題／定理**：定理：每個方陣滿足自身之特徵多項式。
- **證明**：由 adj(λI−A)(λI−A) = χ_A(λ)I 比較 λ 之冪次係數（多項式矩陣恆等式）。本義務逐例以精確 ℚ 驗證。∎
- **義務自證**：✔ 通過　（實例數 20）　χ_A(A)=0，χ(0)=(−1)ⁿdetA，c_{n−1}=−trA

#### C-18　伴隨矩陣（古典 adjugate）

- **類別**：矩陣演算法　　**適用空間**：M_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：adj(A)_{ij} = (−1)^{i+j} M_{ji}（餘因子轉置）。
- **算式**：A·adj A = adj A·A = (det A)·I
- **命題／定理**：定理：A 可逆 ⟺ det A ≠ 0，且 A⁻¹ = adj A/det A。
- **證明**：Laplace 展開沿第 i 列給出對角項 det A；交錯展開（用另一列之餘因子）給出 0。∎
- **義務自證**：✔ 通過　（實例數 20）　A·adjA = (det A)I；xⱼ = detAⱼ/detA

#### C-19　Cramer 法則

- **類別**：矩陣演算法　　**適用空間**：GL_n(𝔽)　　**軌道**：精確 ℚ
- **定義**：xⱼ = det(A_j)/det(A)，A_j 為以 b 取代第 j 行。
- **算式**：x = A⁻¹b = adj(A)b/det A
- **命題／定理**：定理：方陣可逆時解唯一且由行列式商給出。
- **證明**：由 A·adj A = (det A)I 左乘 b；或由行列式之多線性展開 det(A_j)。∎
- **義務自證**：✔ 通過　（實例數 20）　A·adjA = (det A)I；xⱼ = detAⱼ/detA

#### C-20　矩陣冪與 Cayley 變換

- **類別**：矩陣演算法　　**適用空間**：SO(n)、so(n)　　**軌道**：精確 ℚ
- **定義**：mpow 以平方–乘法計算；Cayley(S) = (I−S)(I+S)⁻¹。
- **算式**：A^{m+n} = A^mA^n；S = −Sᵀ ⇒ Q = Cayley(S) ∈ SO(n)
- **命題／定理**：定理：Cayley 變換為 so(n) 至 SO(n)（不含特徵值 −1 者）之有理雙射。
- **證明**：QᵀQ = (I+S)⁻ᵀ(I−S)ᵀ(I−S)(I+S)⁻¹，利用 Sᵀ=−S 與 (I−S),(I+S) 可交換即得 I；det Q = 1 由連續性／直接計算。此變換為有理運算，故於 ℚ 上精確產生正交矩陣。∎
- **義務自證**：✔ 通過　（實例數 15）　A^{m+n}=A^mA^n；Cayley(S) ∈ SO(n)

### D 群 · 抽象內積空間演算法

#### D-01　Gram–Schmidt 正交化（經典）

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：u₁ = x₁，u_k = x_k − Σ_{j<k} (⟨x_k,u_j⟩/⟨u_j,u_j⟩)u_j。
- **算式**：x_k = u_k + Σ_{j<k} r_{jk}u_j（抽象 QR 分解）
- **命題／定理**：定理：span{u₁..u_k} = span{x₁..x_k} 且 uᵢ ⊥ uⱼ (i≠j)。
- **證明**：對 k 歸納：⟨u_k,u_j⟩ = ⟨x_k,u_j⟩ − ⟨x_k,u_j⟩ = 0；轉換矩陣為單位上三角故可逆。∎
- **義務自證**：✔ 通過　（實例數 12）　uᵢ⊥uⱼ；x_j = ΣR_ij u_i；span 保持

#### D-02　改良 Gram–Schmidt（MGS）

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：逐步自剩餘向量扣除已算出之分量。
- **算式**：x_j ← x_j − (⟨x_j,u_k⟩/⟨u_k,u_k⟩)u_k（k 遞增）
- **命題／定理**：定理：精確算術下 MGS ≡ CGS；浮點下正交性損失 O(εκ) 對 O(εκ²)（Björck 1967）。
- **證明**：代數上兩者為同一組遞推之不同結合次序，於精確體上相等（本義務逐項驗證）；數值差異見 H-24。∎
- **義務自證**：✔ 通過　（實例數 12）　精確算術下 MGS ≡ CGS（逐項相等）

#### D-03　標準正交化與體之可開方性

- **類別**：內積演算法　　**適用空間**：ℚⁿ vs ℝⁿ　　**軌道**：精確 ℚ + 數值 ℝ
- **定義**：e_k = u_k/‖u_k‖，需 √⟨u_k,u_k⟩ ∈ 𝔽。
- **算式**：⟨eᵢ,eⱼ⟩ = δᵢⱼ
- **命題／定理**：定理：ℚ 非實閉體，標準正交基一般不存在（√2 ∉ ℚ）；ℝ 上恆存在。
- **證明**：若 ‖u‖² = 2 則 ‖u‖ ∉ ℚ（√2 無理）。故精確軌道只作正交化，正規化留給 ℝ 軌道。本義務同時驗證 ℚ 失敗與 ℝ 成功。∎
- **義務自證**：✔ 通過　（實例數 24）　刻劃定理「ℚ 上可標準正交化 ⟺ GS 各範數平方皆為 ℚ 中完全平方」雙向逐例驗證：否定面 12 組（隨機 ℚ 基底，範數平方非平方 ⇒ 失敗）、肯定面 6 組（有理正交矩陣之行，範數平方 = 1 ⇒ 成功），無一例外；另 6 組 ℝ 上恆成功（開方封閉）

#### D-04　Gram 行列式、k 維體積與 Hadamard 不等式

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：G(x₁..x_k)_{ij} = ⟨xᵢ,xⱼ⟩；vol_k = √det G。
- **算式**：0 ≤ det G ≤ Π‖xᵢ‖²；det G = 0 ⟺ 線性相依
- **命題／定理**：定理：Gram 行列式為平行多面體體積平方；Hadamard 不等式為其上界。
- **證明**：G = B*B（B 為座標矩陣）⇒ det G = |det B|² ≥ 0；正交化後對角化給出 det G = Π‖uᵢ‖² ≤ Π‖xᵢ‖²（因 ‖uᵢ‖ ≤ ‖xᵢ‖）。∎
- **義務自證**：✔ 通過　（實例數 15）　0 ≤ detG ≤ Π‖xᵢ‖²；相依 ⟺ detG=0

#### D-05　正交投影與最佳逼近定理

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：P_W x = Σcⱼwⱼ，c 解正規方程 Gc = b，b_i = ⟨x,wᵢ⟩。
- **算式**：⟨x − P_Wx, w⟩ = 0 ∀w ∈ W；‖x‖² = ‖P_Wx‖² + ‖x−P_Wx‖²
- **命題／定理**：定理（最佳逼近）：存在唯一 w₀ ∈ W 使 ‖x−w₀‖ 最小，且其特徵為殘差 ⊥ W。
- **證明**：正交條件給出 Gram 系統（可逆）⇒ 唯一解；∀w, ‖x−w‖² = ‖x−w₀‖² + ‖w₀−w‖² ≥ ‖x−w₀‖²。∎
- **義務自證**：✔ 通過　（實例數 12）　r⊥W、P²=P、‖x−Px‖ 最小、畢氏分解

#### D-06　點到子空間之距離

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：d(x,W) = ‖x − P_Wx‖。
- **算式**：d(x,W)² = det G(w₁..w_k,x)/det G(w₁..w_k)
- **命題／定理**：命題：d(x,W) = 0 ⟺ x ∈ W；W₁ ⊆ W₂ ⇒ d(x,W₂) ≤ d(x,W₁)。
- **證明**：由最佳逼近定理與投影之單調性（較大子空間之最小值不大於較小者）。∎
- **義務自證**：✔ 通過　（實例數 15）　x∈W ⇒ d=0；W₁⊆W₂ ⇒ d(x,W₂) ≤ d(x,W₁)

#### D-07　投影矩陣之代數特徵

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：[P]_{·j} = coord(P_W b_j)。
- **算式**：P² = P；P*G = GP；rank P = tr P = dim W

- **證明**：冪等性由 P_W|_W = id；自伴性由 ⟨Px,y⟩ = ⟨Px,Py⟩ = ⟨x,Py⟩。跡 = 秩因 P 之特徵值僅 0,1。∎
- **義務自證**：✔ 通過　（實例數 10）　rank P = tr P = dim W

#### D-08　Riesz 表示定理

#### D-09　伴隨算子之矩陣公式

- **義務自證**：✔ 通過　（實例數 16）　⟨Tx,y⟩=⟨x,T*y⟩；ONB 下退化為共軛轉置

#### D-10　Fourier 係數與合成

#### D-11　Bessel 不等式

- **證明**：0 ≤ ‖x − Σ⟨x,eᵢ⟩eᵢ‖² = ‖x‖² − Σ|⟨x,eᵢ⟩|²。∎
- **義務自證**：✔ 通過　（實例數 20）　真子集嚴格小於；完備基取等

#### D-12　Parseval 恆等式

#### D-13　Cauchy–Schwarz 不等式（精確憑證）

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ/ℚ(i)
- **定義**：鬆弛量 δ = ⟨x,x⟩⟨y,y⟩ − |⟨x,y⟩|²。
- **算式**：|⟨x,y⟩|² ≤ ⟨x,x⟩⟨y,y⟩，等號 ⟺ 線性相依
- **命題／定理**：定理（Cauchy–Schwarz）：δ ≥ 0，且 δ = 0 ⟺ {x,y} 線性相依。
- **證明**：令 λ = ⟨x,y⟩/⟨y,y⟩，0 ≤ ⟨x−λy,x−λy⟩ = (⟨x,x⟩⟨y,y⟩−|⟨x,y⟩|²)/⟨y,y⟩。等號 ⟺ x = λy。δ 為體元素，於 ℚ 上可精確判定符號。∎
- **義務自證**：✔ 通過　（實例數 35）　δ = ⟨x,x⟩⟨y,y⟩−|⟨x,y⟩|² ≥ 0，等號 ⟺ 相依

#### D-14　三角不等式（免開方之精確判定）

- **類別**：內積演算法　　**適用空間**：任意 IPSpace　　**軌道**：精確 ℚ
- **定義**：令 a=‖x‖², b=‖y‖², c=‖x+y‖²。
- **算式**：‖x+y‖ ≤ ‖x‖+‖y‖ ⟺ (c−a−b ≤ 0) ∨ ((c−a−b)² ≤ 4ab)
- **命題／定理**：定理：三角不等式等價於上述有理判定式（避免在 ℚ 上開方）。
- **證明**：c ≤ a+b+2√(ab) ⟺ c−a−b ≤ 2√(ab)；若左式 ≤ 0 顯然成立，否則兩邊平方。∎
- **義務自證**：✔ 通過　（實例數 30）　精確判定 (c−a−b ≤ 0) ∨ ((c−a−b)² ≤ 4ab)

#### D-15　平行四邊形律

- **類別**：內積演算法　　**適用空間**：P₅、ℚ⁵、Sym₃　　**軌道**：精確 ℚ
- **定義**：缺陷量 = ‖x+y‖²+‖x−y‖² − 2‖x‖² − 2‖y‖²。
- **算式**：‖x+y‖² + ‖x−y‖² = 2‖x‖² + 2‖y‖²
- **命題／定理**：定理（Jordan–von Neumann）：賦範空間之範數源自內積 ⟺ 滿足平行四邊形律。
- **證明**：展開內積直接得；逆向由極化恆等式構造內積並驗證雙線性。本義務於三個不同空間驗證缺陷恆為 0。∎
- **義務自證**：✔ 通過　（實例數 45）　三個不同空間上恆等式皆精確為 0

#### D-16　實極化恆等式

#### D-17　複極化恆等式

#### D-18　畢氏定理與其逆

#### D-20　等距判定與 Gram 之基底變換律

#### D-23　夾角與餘弦相似度

### E 群 · 具體空間之專屬定理

#### E-01　Legendre 多項式 = 單項式基之 Gram–Schmidt

- **類別**：多項式空間　　**適用空間**：S11 P_n(L²[−1,1])　　**軌道**：精確 ℚ

- **義務自證**：✔ 通過　（實例數 6）　首一化後逐項相等（精確 ℚ）

#### E-02　Legendre 正交性與範數

#### E-03　Chebyshev 合成律 T_m∘T_k = T_{mk}

- **命題／定理**：定理：Chebyshev 多項式族於合成下構成乘法么半群同態 (ℕ,×) → (𝔽[x],∘)。
- **證明**：由 T_n(cos θ) = cos nθ 得 T_m(T_k(cos θ)) = cos(mkθ)；兩多項式於無窮多點相等故恆等。本義務以 𝔽[x] 中之精確係數相等驗證（非數值近似）。∎
- **義務自證**：✔ 通過　（實例數 24）　並驗三項遞推

#### E-04　Vandermonde 行列式公式

- **類別**：多項式空間　　**適用空間**：S13 離散點值空間　　**軌道**：精確 ℚ
- **定義**：V_{kj} = t_k^j。
- **算式**：det V = Π_{i<j}(t_j − t_i)
- **命題／定理**：定理：節點相異 ⟺ V 可逆 ⟺ 插值問題唯一可解。
- **證明**：兩邊皆為 t 之多項式；t_i = t_j 時皆為 0 ⇒ 右式整除左式；比較次數 n(n−1)/2 與領導係數。∎
- **義務自證**：✔ 通過　（實例數 20）　det V = Π_{i<j}(t_j−t_i) ≠ 0（節點相異）

#### E-05　Lagrange 插值與唯一性

- **類別**：多項式空間　　**適用空間**：S13　　**軌道**：精確 ℚ
- **定義**：L(x) = Σ_i y_i Π_{j≠i}(x−t_j)/(t_i−t_j)。
- **算式**：L(t_k) = y_k；deg L < m
- **命題／定理**：定理：給定 m 個相異節點，存在唯一次數 < m 之插值多項式。
- **證明**：存在性由基本多項式之構造；唯一性由差值多項式有 m 個根但次數 < m ⇒ 恆零。本義務並與 Vandermonde 線性系統之解交叉驗證。∎
- **義務自證**：✔ 通過　（實例數 20）　p(tᵢ)=yᵢ；與 Vandermonde 解一致

#### E-06　微分算子之冪零性與 Heisenberg 關係

- **類別**：多項式空間　　**適用空間**：S11 / 算子代數　　**軌道**：精確 ℚ
- **定義**：D_{i,i+1} = i+1（微分）；X_{i+1,i} = 1（乘以 x，截斷）。

- **證明**：D 降次 1 ⇒ Dⁿ = 0 且 D^{n−1}x^{n−1} = (n−1)! ≠ 0；χ_D = λⁿ 由上三角（嚴格）矩陣；[D,X]x^k = (k+1)x^k − kx^k = x^k。∎
- **義務自證**：✔ 通過　（實例數 6）　D^dim=0 且 D^{dim−1}≠0，χ_D=λ^dim，[D,X]=I

#### E-07　Hilbert Gram 矩陣之正定性與病態性

- **類別**：多項式空間　　**適用空間**：S12 P_n(L²[0,1])　　**軌道**：精確 ℚ + 數值 ℝ

### F 群 · 空間構造子（組合爆炸）

### G 群 · 外代數與行列式幾何

#### G-01　楔積之反交換律

- **義務自證**：✔ 通過　（實例數 15）　Λ(𝔽ⁿ) 為結合分次代數（dim = 2ⁿ）

#### G-03　Gram 行列式定理（Λᵏ 之內積）

- **證明**：Λⁿ 一維且楔積交錯多線性，取標準基得係數即 det。相依時某 vᵢ 為其餘之線性組合 ⇒ 展開後每項含重複因子 ⇒ 0。∎
- **義務自證**：✔ 通過　（實例數 20）　v₁∧…∧v_n = det(V)e_{1…n}；相依 ⇒ 0

#### G-05　Hodge 星算子之對合律

- **類別**：外代數　　**適用空間**：Λᵏ ↔ Λ^{n−k}　　**軌道**：精確 ℚ
- **定義**：⋆e_I = ε(I,Iᶜ)e_{Iᶜ}。
- **算式**：⋆⋆ = (−1)^{k(n−k)}·id
- **命題／定理**：定理：⋆ 為 Λᵏ 與 Λ^{n−k} 間之等距同構，且平方為符號。
- **證明**：ε(I,Iᶜ)ε(Iᶜ,I) = (−1)^{k(n−k)}（交換兩塊之逆序數）。等距性由基底之雙射與符號為 ±1。∎
- **義務自證**：✔ 通過　（實例數 90）　⋆⋆ = (−1)^{k(n−k)}·id

#### G-06　Hodge 星與內積之相容性

- **類別**：外代數　　**適用空間**：Λᵏ(𝔽ⁿ)　　**軌道**：精確 ℚ
- **定義**：vol = e_{1…n}。
- **算式**：α ∧ ⋆β = ⟨α,β⟩·vol
- **命題／定理**：定理：此式可作為 Hodge 星之不依賴基底之定義。
- **證明**：於基底元上 e_I ∧ ⋆e_J = δ_{IJ}·ε(I,Iᶜ)²·vol = δ_{IJ}vol；雙線性延拓。∎
- **義務自證**：✔ 通過　（實例數 36）　Hodge 星與內積之相容性

#### G-07　三維叉積之古典恆等式

- **類別**：外代數　　**適用空間**：Λ²(𝔽³) ≅ 𝔽³　　**軌道**：精確 ℚ
- **定義**：a×b = ⋆(a∧b)。
- **算式**：‖a×b‖² = ‖a‖²‖b‖² − ⟨a,b⟩²（Lagrange）；a×(b×c)+b×(c×a)+c×(a×b) = 0（Jacobi）；⟨a,b×c⟩ = det[a b c]
- **命題／定理**：定理：(ℝ³,×) 為李代數 so(3)，且叉積為 Hodge 星與楔積之複合。
- **證明**：Lagrange 恆等式即 G-03 於 k=2 之特例；Jacobi 由 BAC–CAB 展開；三重積為 Λ³ 之係數。∎
- **義務自證**：✔ 通過　（實例數 25）　⋆(a∧b) 之全部古典恆等式

#### G-08　廣義叉積（n−1 個向量之 Hodge 補）

- **類別**：外代數　　**適用空間**：𝔽ⁿ　　**軌道**：精確 ℚ
- **定義**：x = ⋆(v₁∧…∧v_{n−1})。
- **算式**：⟨x,vᵢ⟩ = 0 ∀i；‖x‖² = det Gram(v₁..v_{n−1})
- **命題／定理**：定理：廣義叉積垂直於所有輸入向量，其長度為 (n−1) 維體積。
- **證明**：⟨x,vᵢ⟩·vol = vᵢ∧(v₁∧…∧v_{n−1}) = 0（重複因子）；長度由 G-03 與 ⋆ 之等距性。∎
- **義務自證**：✔ 通過　（實例數 24）　⟨x,vᵢ⟩=0；‖x‖² = det Gram = (n−1)體積²

#### G-09　Plücker 座標與 Plücker 關係

- **類別**：外代數　　**適用空間**：Grassmann 流形 Gr(k,n)　　**軌道**：精確 ℚ
- **定義**：p_I = det V[I,:]。
- **算式**：p₀₁p₂₃ − p₀₂p₁₃ + p₀₃p₁₂ = 0（k=2, n≥4）
- **命題／定理**：定理：可分解 2-向量之座標滿足 Plücker 二次關係（Grassmann 流形之方程）。

- **義務自證**：✔ 通過　（實例數 15）　(v₁∧v₂)_I = det V[I,:]；p₀₁p₂₃−p₀₂p₁₃+p₀₃p₁₂=0

### H 群 · 數值線性代數（ℝ 軌道．殘差憑證）

#### H-01　Cholesky 分解

- **類別**：數值分解　　**適用空間**：SPD 矩陣　　**軌道**：數值 ℝ
- **定義**：A = LLᵀ，L 下三角且 l_ii > 0。
- **算式**：l_jj = √(a_jj − Σ_{k<j}l_jk²)；殘差 ‖A−LLᵀ‖_max ≤ ε
- **命題／定理**：定理：A 對稱正定 ⟺ Cholesky 分解存在且唯一；演算法為後向穩定。
- **證明**：對 n 歸納（分塊消去）；正定性保證根號下為正。義務回報實測殘差 ≈ 10⁻¹⁵ 並驗證不定矩陣被否決。∎
- **義務自證**：✔ 通過　（實例數 10）　‖A−LLᵀ‖_max = 3.553e-15 ≤ ε；不定矩陣被否決

#### H-02　LDLᵀ 分解與 Sylvester 慣性律

- **類別**：數值分解　　**適用空間**：對稱矩陣　　**軌道**：數值 ℝ
- **定義**：A = LDLᵀ，L 單位下三角，D 對角。
- **算式**：慣性 (p,z,m) 不隨合同變換改變
- **命題／定理**：定理（Sylvester 慣性律）：對稱矩陣之正／零／負特徵值個數為合同不變量。
- **證明**：若 A = SBSᵀ（S 可逆）則二次型之最大正定子空間維數相同。義務以 LDL 之 D 符號計數與 Jacobi 譜之符號計數交叉驗證。∎
- **義務自證**：✔ 通過　（實例數 8）　‖A−LDLᵀ‖_max = 3.997e-15；(p,z,m) 與譜一致

#### H-03　Householder QR 分解

- **類別**：數值分解　　**適用空間**：M_{m×n}(ℝ)　　**軌道**：數值 ℝ
- **定義**：以反射 H_k = I − 2vvᵀ/vᵀv 逐行消去。
- **算式**：A = QR；QᵀQ = I；R 上三角
- **命題／定理**：定理：Householder QR 為後向穩定（‖ΔA‖ = O(ε‖A‖)），優於 Gram–Schmidt。
- **證明**：每步反射為精確正交矩陣，捨入誤差不放大；殘差憑證 ‖A−QR‖、‖QᵀQ−I‖ ≈ 10⁻¹⁵。∎
- **義務自證**：✔ 通過　（實例數 10）　‖A−QR‖=5.551e-15，‖QᵀQ−I‖=8.882e-16

#### H-04　Givens 旋轉 QR 分解

- **類別**：數值分解　　**適用空間**：M_{m×n}(ℝ)　　**軌道**：數值 ℝ
- **定義**：以平面旋轉逐一消去次對角元素。
- **算式**：G(i,j,θ)ᵀA 消去 a_{ji}；A = QR
- **命題／定理**：定理：Givens QR 與 Householder QR 之 R 至對角符號唯一（QR 分解之唯一性）。
- **證明**：滿秩時 R 之對角取正可唯一化；義務驗證兩法之 |R_ii| 一致。∎
- **義務自證**：✔ 通過　（實例數 10）　‖A−QR‖=1.776e-15；|R_ii| 與 Householder 一致

#### H-05　Hessenberg 化簡

- **類別**：數值分解　　**適用空間**：M_n(ℝ)　　**軌道**：數值 ℝ
- **定義**：以 Householder 反射作正交相似變換。
- **算式**：QᵀAQ = H（h_{ij} = 0 當 i > j+1）
- **命題／定理**：定理：任意方陣正交相似於上 Hessenberg 形；對稱時為三對角。
- **證明**：逐行以反射消去第 k 行第 k+2 以下元素，相似變換保持已完成之零結構。∎
- **義務自證**：✔ 通過　（實例數 8）　‖A−QHQᵀ‖=5.551e-15；次對角以下為 0

#### H-06　Jacobi 特徵分解（譜定理）

- **類別**：數值特徵值　　**適用空間**：對稱矩陣　　**軌道**：數值 ℝ
- **定義**：反覆以平面旋轉消去最大非對角元。
- **算式**：A = VΛVᵀ；VᵀV = I；Av_k = λ_kv_k
- **命題／定理**：定理（譜定理）：實對稱矩陣正交可對角化；Jacobi 法二次收斂。
- **證明**：每次旋轉使非對角 Frobenius 範數嚴格下降（off(A') = off(A) − 2a_{pq}²）。殘差憑證 ‖A−VΛVᵀ‖ ≈ 10⁻¹⁵。∎
- **義務自證**：✔ 通過　（實例數 8）　‖A−VΛVᵀ‖=3.997e-15，‖VᵀV−I‖=1.332e-15

#### H-07　無位移 QR 迭代

- **類別**：數值特徵值　　**適用空間**：對稱矩陣　　**軌道**：數值 ℝ
- **定義**：A_{k+1} = R_kQ_k，其中 A_k = Q_kR_k。
- **算式**：A_k → diag(λ)（模長相異時）
- **命題／定理**：定理：QR 迭代之 A_k 皆正交相似於 A，且在特徵值模長相異時收斂至上三角。
- **證明**：A_{k+1} = Q_kᵀA_kQ_k 故相似；收斂性由冪法之推廣（子空間迭代）。義務與 Jacobi 之譜交叉驗證。∎
- **義務自證**：✔ 通過　（實例數 6）　對角元 → 特徵值，最大偏差 1.954e-14

#### H-08　單邊 Jacobi SVD

- **類別**：數值分解　　**適用空間**：M_{m×n}(ℝ)　　**軌道**：數值 ℝ
- **定義**：對 A 之行作旋轉使其兩兩正交；行範數即奇異值（遞減排序）。
- **算式**：A = UΣVᵀ；σᵢ² = λᵢ(AᵀA)；σ₁ = ‖A‖₂
- **命題／定理**：定理（SVD）：任意矩陣可分解為正交×對角×正交；奇異值唯一。
- **證明**：AᵀA 對稱半正定，取其譜分解即得 V 與 σ；U 由 Av/σ 定義並補成正交基。義務驗證殘差、正交性、排序與 σ²≡λ(AᵀA)。∎
- **義務自證**：✔ 通過　（實例數 8）　‖A−UΣVᵀ‖=2.220e-15

#### H-09　Moore–Penrose 偽逆

- **定義**：A⁺ = VΣ⁺Uᵀ（σ > tol 者取倒數）。
- **算式**：AA⁺A = A；A⁺AA⁺ = A⁺；(AA⁺)ᵀ = AA⁺；(A⁺A)ᵀ = A⁺A
- **命題／定理**：定理：滿足 Penrose 四條件之矩陣唯一；x = A⁺b 為最小範數最小二乘解。
- **證明**：由 SVD 逐條驗證；唯一性為標準論證。滿秩時 A⁺ = (AᵀA)⁻¹Aᵀ（義務一併驗證）。∎

#### H-10　極分解 A = UP

- **算式**：A = UP；UᵀU = I；P = Pᵀ ⪰ 0

#### H-11　矩陣指數（縮放–平方 + Taylor）

- **命題／定理**：定理：矩陣指數之 Jacobi 公式 det(e^A) = e^{tr A}。
- **證明**：由 Jordan 形或 d/dt det(e^{tA}) = tr(A)det(e^{tA})；可換性條件下之加法律由級數重排。∎
- **義務自證**：✔ 通過　（實例數 6）　e^Ae^{−A}=I；det e^A = e^{tr A}；殘差 5.507e-14

#### H-12　對稱正定矩陣平方根

- **命題／定理**：定理：SPD 矩陣之正定平方根存在且唯一。

#### H-13　冪迭代與 Rayleigh 商

#### H-14　2-範數條件數 κ₂

- **義務自證**：✔ 通過　（實例數 8）　κ₂(Q)=1；κ₂(H₆)≈1.495e7

#### H-15　共軛梯度法

- **類別**：迭代解法　　**適用空間**：SPD 線性系統　　**軌道**：數值 ℝ
- **定義**：以 A-共軛方向逐步最小化 ½xᵀAx − bᵀx。

- **證明**：殘差構成正交族、方向構成 A-正交族 ⇒ 至多 n 個；最佳性由 Galerkin 條件。義務以恰 n 次迭代後之殘差為憑證。∎
- **義務自證**：✔ 通過　（實例數 8）　恰 n 次迭代後 ‖Ax−b‖_max = 1.110e-15

#### H-16　Gauss–Seidel 迭代

- **類別**：迭代解法　　**適用空間**：對角佔優／SPD 系統　　**軌道**：數值 ℝ
- **定義**：x_i ← (b_i − Σ_{j<i}a_{ij}x_j − Σ_{j>i}a_{ij}x_j)/a_ii。
- **算式**：x^{(k+1)} = (D+L)⁻¹(b − Ux^{(k)})

- **證明**：迭代矩陣 M = −(D+L)⁻¹U 之譜半徑 < 1（Householder–John 定理）。義務以殘差為憑證。∎
- **義務自證**：✔ 通過　（實例數 6）　殘差 6.661e-16

#### H-17　Lanczos 三對角化（完全再正交化）

- **類別**：Krylov 方法　　**適用空間**：對稱矩陣　　**軌道**：數值 ℝ
- **定義**：以 Krylov 子空間 K_k(A,q₁) 之正交基建構三對角 T。
- **算式**：QᵀAQ = T（三對角）；AQ = QT + β q_{k+1}e_kᵀ
- **命題／定理**：定理：Lanczos 為對稱矩陣之 Arnoldi 特例；T 之特徵值為 Ritz 值。
- **證明**：對稱性使 Arnoldi 之 Hessenberg 退化為三對角；完全再正交化消除浮點正交性損失。殘差憑證 ‖QᵀAQ−T‖ ≈ 10⁻¹⁵。∎
- **義務自證**：✔ 通過　（實例數 6）　‖QᵀAQ−T‖ = 1.776e-15；T 三對角

#### H-18　Arnoldi 分解

- **類別**：Krylov 方法　　**適用空間**：一般方陣　　**軌道**：數值 ℝ
- **定義**：Gram–Schmidt 於 Krylov 序列 {v, Av, A²v, …}。
- **算式**：QᵀAQ = H（上 Hessenberg）
- **命題／定理**：定理：Arnoldi 給出 Krylov 子空間上之正交投影算子矩陣。
- **證明**：逐步正交化保證 H 為上 Hessenberg；完整 k=n 時 Q 為正交方陣。∎
- **義務自證**：✔ 通過　（實例數 6）　‖QᵀAQ−H‖ = 5.940e-15；H 上 Hessenberg

#### H-19　DFT 矩陣之么正性與循環矩陣對角化

- **定義**：F_{jk} = ω^{jk}/√n，ω = e^{−2πi/n}。

- **證明**：循環矩陣為位移算子 S 之多項式，而 S 之特徵向量為 Fourier 基。義務驗證非對角元為 0 且對角元等於 √n·Fc。∎
- **義務自證**：✔ 通過　（實例數 9）　‖F*F−I‖=4.441e-16；F C F* 之非對角為 0

#### H-20　快速 Fourier 變換（遞迴 radix-2）

- **類別**：變換家族　　**適用空間**：ℂⁿ（n = 2^k）　　**軌道**：數值 ℝ/ℂ
- **定義**：分治：偶數項與奇數項之 DFT 再以旋轉因子合併。

- **定義**：H(A) = ∏ᵢ ⌈√(Σⱼ aᵢⱼ²)⌉；取最小 k 使 ∏_{i<k} pᵢ > 2H。

- **命題／定理**：定理（Hadamard）：行列式之絕對值不超過列向量歐氏範數之積。推論：k 個素數即足以唯一決定 det A。
- **證明**：det 為列向量張成之平行多面體之有向體積；Gram–Schmidt 給出 |det| = ∏‖a*ᵢ‖ 而 ‖a*ᵢ‖ ≤ ‖aᵢ‖（投影不增長度）。配合定理 Λ1-3 即得提升唯一性。義務中逐例驗證 |det| ≤ H 與 ∏p > 2H。∎
- **義務自證**：✔ 通過　（實例數 24）　24 個實例：|det| ≤ ∏列範數；所選素數之積 > 2·界（提升唯一性之前提成立）

#### K-04　整數行列式之多模 CRT（對照 Bareiss）

- **類別**：ℤ 層加速　　**適用空間**：ℤ^{n×n}（源自 C-05 行列式）　　**軌道**：精確 ℤ（CRT）
- **定義**：dᵢ = det(φ_{pᵢ}A) ∈ 𝔽pᵢ 以前向消去求得（≈n³/3 次字乘法），再 CRT 提升。
- **算式**：φ_p(det A) = det(φ_p A)；det A = CRT_sym(d₁,…,d_k)
- **命題／定理**：定理：det 為矩陣元之整係數多項式，與環同態 φ_p 交換；故多模路徑之輸出與 Bareiss 無分數消去逐位相同。
- **證明**：環同態保持由 +,−,× 組成之多項式映射（推論 Λ1-2）；取 ∏p > 2·Hadamard 界後由對稱提升之唯一性得等式。基準路徑 Bareiss 之每個中間量為子式，位元長度隨步數線性增長（係數膨脹）；模路徑之中間量恆 ≤ 62 位元。∎
- **義務自證**：✔ 通過　（實例數 11）　10 組三路一致（CRT = Bareiss = ℚ 高斯）；n=16 b=256 使用 136 素數：基準 2148821 字乘（7693 位元）→ 加速 480115 字乘（4216 位元），增益 ×4.48

#### K-05　整數矩陣秩之單素數下界篩與多素數確證

- **類別**：ℤ 層加速　　**適用空間**：ℤ^{m×n}（源自 C-04 秩）　　**軌道**：精確 ℤ（CRT）
- **定義**：rank A ≔ max over primes of rank_{𝔽p}(φ_p A)。
- **算式**：rank_{𝔽p}(φ_p A) ≤ rank_ℚ(A)，等號對幾乎所有 p 成立
- **命題／定理**：命題：模約化只會降秩不會升秩；取多個素數之極大值即得真秩（壞素數為整除某個非零極大子式者，個數有限）。
- **證明**：rank ≥ r ⇔ 存在非零 r 階子式 Δ。φ_p(Δ) ≠ 0 ⇒ Δ ≠ 0 給出下界；反向僅在 p | Δ 時失效，而 Δ ≠ 0 之質因子有限。義務以「指定秩之乘積矩陣 A = BC」逐例驗證等號與下界性。∎
- **義務自證**：✔ 通過　（實例數 14）　14 組指定秩之實例：多素數取極大值 = 真秩；單素數之秩恆為下界（命題 Λ2-6）

#### K-06　整數特徵多項式之多模 Hessenberg CRT

- **類別**：ℤ 層加速　　**適用空間**：ℤ^{n×n}（源自 C-16 Faddeev–LeVerrier）　　**軌道**：精確 ℤ（CRT）
- **定義**：於 𝔽p 上先相似化為上 Hessenberg，再以 Cohen 之遞迴 O(n³) 求 χ_A mod p；逐係數 CRT 提升。
- **算式**：p_m(x) = (x − H_{m−1,m−1})p_{m−1}(x) − Σ_{i=1}^{m−1} H_{m−i−1,m−1}(∏_{j=1}^{i} H_{m−j,m−j−1}) p_{m−i−1}(x)
- **命題／定理**：定理：相似變換保持特徵多項式；Hessenberg 遞迴給出 χ_H = p_n；係數界 |cᵢ| ≤ 2ⁿ‖A‖_∞ⁿ 決定所需素數個數。
- **證明**：消去之列運算與其逆之行運算合成為相似變換 S⁻¹AS；遞迴式由末行之 Laplace 展開得出，次對角線之連乘積恰為唯一非零路徑之權重。係數為特徵值之基本對稱多項式，由 Gershgorin 得 |λ| ≤ ‖A‖_∞。∎
- **義務自證**：✔ 通過　（實例數 7）　7 組與 Faddeev–LeVerrier 逐係數相同；n=11 用 13 素數：基準 281913 字乘（359 位元）→ 加速 28582 字乘（403 位元），增益 ×9.86

#### K-07　伴隨矩陣之多模 CRT（含 plan_zadj 門檻 n ≈ 7）

- **類別**：ℤ 層加速　　**適用空間**：ℤ^{n×n}（源自 C-18 adjugate）　　**軌道**：精確 ℤ（CRT）
- **定義**：於 det ≢ 0 (mod p) 之素數上取 adj A ≡ det(A)·A⁻¹ (mod p)；det ≡ 0 之素數視為壞素數並跳過。
- **算式**：A·adj A = adj A·A = (det A)·I；|（adj A)_{ij}| ≤ H(A)
- **命題／定理**：命題：adj A 之元素為 (n−1) 階餘因子，受同一 Hadamard 界控制；壞素數集合有限，跳過不影響正確性。
定理（門檻必要性）：伴隨矩陣之輸出為 n² 個整數而非 1 個，故 CRT 重建項帶 n² 因子；實測 n=5 ×0.35、n=8 ×1.70、n=11 ×5.79，交叉點 n ≈ 7。無條件加速在 n < 7 時為淨虧，故須經 plan_zadj 分派。
- **證明**：餘因子為子式，Hadamard 界對子式亦成立（去一列一行只會縮小界）。det A ≠ 0 時只有有限多個 p 整除 det A，故可用之素數充裕。義務同時以 A·adj A = det(A)·I 作獨立覆核。∎
- **義務自證**：✔ 通過　（實例數 4）　n = 4,6,7,8 與 madj 逐項相同且滿足 A·adj A = det(A)·I；壞素數跳過 0 次；plan_zadj 採用加速之 2 例增益皆 > 1（最高 ×1.74），拒絕之例最高僅 ×0.59（bits=16 時交叉點落於 n = 6|7 之間：n≤6 拒絕、n≥7 採用，定理 Λ3-13）

#### K-08　Freivalds 乘積篩（A 管：單向可靠之否決）

- **類別**：篩選管線　　**適用空間**：ℤ^{n×n}（源自 C-01 矩陣乘法／C-07 乘性）　　**軌道**：多模 𝔽p
- **定義**：取隨機 r ∈ 𝔽pⁿ，比較 A(Br) 與 (C)r 於 𝔽p 中是否相等；成本 O(n²) 字乘法。
- **算式**：AB = C ⇒ ∀p,r : φ_p(A)(φ_p(B)r) = φ_p(C)r（逆否即否決規則）
- **命題／定理**：定理（單向可靠性）：若某素數某向量下像不等，則 AB ≠ C 必然成立（零誤否決）。反向誤收之機率 ≤ 1/p + （壞素數比例）。
- **證明**：φ_p 為環同態且矩陣乘法由 +,× 組成，故等式必被保持；取逆否命題得否決之零誤性。誤收：令 D = AB − C ≠ 0，則 Dr = 0 之 r 落在一個真子空間，機率 ≤ 1/p；再考慮 p | D 之壞素數有限。義務以 40 組真實例（零誤否決）與 40 個植入單點錯誤（全數捕捉）實測。∎
- **義務自證**：✔ 通過　（實例數 80）　40 組真實例零誤否決；40 個植入錯誤全數捕捉；n=14 篩 1442 字乘 vs 完整乘積 2744 字乘（×1.9）

#### K-09　Gram 行列式／k 維體積之 CRT 加速

- **類別**：ℤ 層加速　　**適用空間**：ℤ^{m×k}（源自 D-04 Gram 行列式、G-03）　　**軌道**：精確 ℤ（CRT）
- **定義**：G = AᵀA（整數對稱半正定），det G 以多模 CRT 求得。
- **算式**：vol_k(a₁,…,a_k)² = det G；det G = 0 ⇔ 行向量相依
- **命題／定理**：定理：Gram 行列式非負，且為 k 維平行多面體體積之平方；其退化等價於線性相依。
- **證明**：G = AᵀA ⇒ xᵀGx = ‖Ax‖² ≥ 0 故半正定、det ≥ 0。det G = 0 ⇔ ∃x≠0, Ax = 0 ⇔ 行相依。AᵀA 之元素為內積，位元長度約為輸入之兩倍，故此處係數膨脹尤其嚴重，加速增益明顯。∎
- **義務自證**：✔ 通過　（實例數 9）　8 組 det(AᵀA) ≥ 0 且退化 ⇔ 行相依；10 維 Gram：基準 84007 字乘（2901 位元）→ 加速 68894 字乘（1643 位元），增益 ×1.22

#### K-10　ℤ 層分派器之正向性自證

- **類別**：分派策略　　**適用空間**：加速層之總控　　**軌道**：多模 𝔽p
- **定義**：δ(n,b) = [pred_fast·5 < pred_base·4]；pred 由成本模型（schoolbook 字乘法）給出，含 25% 安全邊際。
- **算式**：δ = true ⇒ cost_fast < cost_base（逐點不劣）

### L 群 · 加速層 ℚ 管（Fp 層級有理數重建篩選）

#### L-01　有理數重建：格–歐幾里得與唯一性界

- **類別**：有理重建　　**適用空間**：加速層 Λ1（ℚ 層之縫合）　　**軌道**：精確 ℚ（重建+憑證）
- **定義**：對 (M,u) 作擴充歐幾里得，於第一個餘數 rᵢ ≤ N 處輸出 n/d = rᵢ/tᵢ；取 N = D = ⌊√((M−1)/2)⌋。
- **算式**：M > 2ND ⇒ 滿足 |n| ≤ N, 0 < d ≤ D, n ≡ u·d (mod M) 之既約分數唯一
- **命題／定理**：定理（Wang）：上述條件下重建唯一且可由歐幾里得餘數序列讀出。推論：界不足時演算法安全失敗（回 None）而非輸出錯誤答案。
- **證明**：唯一性：兩組解給出 n₁d₂ ≡ n₂d₁ (mod M) 且 |n₁d₂ − n₂d₁| ≤ 2ND < M ⇒ 兩者相等。可讀出性：餘數序列滿足 rᵢ = sᵢM + tᵢu 且 |tᵢ|rᵢ₋₁ < M，於跨越 N 之處即得候選。本實作另以 n ≡ u·d (mod M) 與 gcd(n,d)=1 作輸出前之驗證，故不可能輸出未經檢核之值。∎
- **義務自證**：✔ 通過　（實例數 120）　80 個界內實例全數精確還原（2ND < M）；40 個界外實例無一給出未經驗證之結果（12 次明確失敗）

#### L-02　批次求逆（Montgomery 技巧）

- **類別**：多模原子層　　**適用空間**：加速層 Λ0（ℚ 層與插值之熱點）　　**軌道**：多模 𝔽p
- **定義**：Pᵢ = v₀⋯v_{i−1}，A = (∏v)⁻¹；後向遞推 vᵢ⁻¹ = A·(∏_{j>i}vⱼ)·Pᵢ。
- **算式**：n 個逆元 = 1 次求逆 + 3n 次乘法
- **命題／定理**：定理：上式確為 vᵢ 之逆；成本由 n 次 Fermat 冪（各約 46 次乘法）降為 O(n)。
- **證明**：直接計算 A·∏_{j>i}vⱼ·Pᵢ = (∏v)⁻¹·(∏v)/vᵢ = vᵢ⁻¹。義務驗證 480 個逆元與 Fermat 路徑逐一相同、v·v⁻¹ = 1，並實測 64 個逆元之乘法次數比（×15.4）。此優化使 Newton 插值之內層由 O(n²) 次求逆降為 O(n) 次。∎
- **義務自證**：✔ 通過　（實例數 480）　480 個逆元與 Fermat 路徑逐一相同且 v·v⁻¹ = 1；64 個逆元：批次 253 次乘法 vs 逐個 Fermat 3904 次（×15.4）

#### L-03　ℚ 線性方程組：多模解 + 有理重建 + 事後憑證

- **類別**：ℚ 層加速　　**適用空間**：ℚ^{n×n}（源自 C-09 線性方程組、C-19 Cramer）　　**軌道**：精確 ℚ（重建+憑證）
- **定義**：清分母得整數系統 A′x = b′；逐素數解 mod p、逐座標 CRT；重建穩定後以整數算術驗證 A′x̂ = b′。
- **算式**：x = A⁻¹b；憑證 A′x̂ − b′ = 0（精確）
- **命題／定理**：定理（無條件正確性）：A 非奇異且憑證通過 ⇒ x̂ 即唯一解，與素數個數、重建界皆無關。
- **證明**：A 非奇異 ⇒ 解唯一；x̂ 滿足方程 ⇒ x̂ 為該解。故 C 管把「機率／界」論證轉為「確定性」論證：B 管只負責猜，C 管負責證。義務以高斯消去與函式庫 msolve 三路對照，並實測 n=14 之增益。∎
- **義務自證**：✔ 通過　（實例數 11）　11 組與高斯消去、msolve 三路一致，全部通過事後憑證 Ax=b；n=14 用 8 素數：基準 223758 字乘（280 位元）→ 加速 32772 字乘（248 位元），增益 ×6.83

#### L-04　ℚ 反矩陣之多模重建與憑證 A·X = I

- **類別**：ℚ 層加速　　**適用空間**：ℚ^{n×n}（源自 C-08 反矩陣）　　**軌道**：精確 ℚ（重建+憑證）
- **定義**：A = A_z/d ⇒ A⁻¹ = d·A_z⁻¹；逐素數求 A_z⁻¹ mod p、逐元 CRT、有理重建，再以整數算術驗證 A·X = I。
- **算式**：A·X = I 之精確整數驗證：A_z·X_z = (d·d_X)·I
- **命題／定理**：定理：憑證通過 ⇒ X = A⁻¹（逆元唯一）。
- **證明**：群中逆元唯一：若 AX = I 且 A 可逆，則 X = A⁻¹AX = A⁻¹。憑證以清分母後之整數乘法完成，成本 O(n³) 但運算元為已重建之小整數，遠低於消去過程中之膨脹中間量。∎
- **義務自證**：✔ 通過　（實例數 9）　9 組與 minv 逐項相同且通過憑證 A·X = I（7 素數）；n=12：基準 389227 字乘（229 位元）→ 加速 39134 字乘（217 位元），增益 ×9.95

#### L-05　ℚ 之 RREF 多模重建 —— 誠實反例（實測 ×0.15，不應加速）

- **類別**：ℚ 層反例　　**適用空間**：ℚ^{m×n}（源自 C-03 Gauss–Jordan）　　**軌道**：精確 ℚ（重建+憑證）
- **定義**：對增廣 [A_z | I] 逐素數作 RREF，只取 A 部分之樞軸型態；取最大秩之型態作 CRT 與重建，輸出 (R, T)。
- **算式**：T·A = R，T 可逆；rank A = #{樞軸 < n}
- **命題／定理**：定理（正確性）：RREF 唯一；模約化只會降秩，故取最大秩之樞軸型態即真型態；憑證 T·A = R ∧ det T ≠ 0 給出無條件正確性。
定理（負面結果，本條之主張）：本路徑對 ℚ 直接消去為淨虧，且虧損隨 n 擴大 —— 實測 ×0.25／×0.22／×0.15（n=6/10/14）。故本條列為反例，不計入加速層。
- **證明**：正確性：RREF 之唯一性為標準結果（與樞軸選擇無關）。壞素數使某些樞軸消失而降秩，取極大值排除之。T 由增廣之單位塊承載列運算；增廣部分之額外樞軸只會對「A 部分為零列」之列作運算，不影響 A 部分，故截取前 n 行仍為 RREF(A)。∎
負面結果之成因：CRT 加速之適用條件為「中間量 ≫ 輸出量」。RREF 之輸出為 m×n 個有理數，每個都需獨立之 Θ(k²) CRT 累積與 Θ(w²) 有理重建，合計 Θ(mn·k²)；而 ℚ 直接消去之中間係數膨脹並不比輸出更嚴重，故無膨脹可省。虧損隨 n 擴大即因 CRT 項之 mn 因子隨 n² 成長而消去項僅 n³ 成長。∎
- **義務自證**：✔ 通過　（實例數 11）　11 組與 mrref 之 R 及秩完全相同；全部通過憑證 T·A = R ∧ det T ≠ 0；含秩虧實例

#### L-06　正交投影係數之模重建（Gram 正規方程）

- **類別**：ℚ 層加速　　**適用空間**：任意 IPSpace（源自 D-05 正交投影）　　**軌道**：精確 ℚ（重建+憑證）
- **定義**：P_W x = Σcⱼwⱼ，c 解 Gc = b，G_{ij} = ⟨w_j, w_i⟩，b_i = ⟨x, w_i⟩；G c = b 以 ℚ 層加速管求解。
- **算式**：⟨x − P_Wx, w⟩ = 0 ∀w ∈ W
- **命題／定理**：定理（最佳逼近）：殘差與子空間正交之條件等價於正規方程；加速後之係數仍使殘差精確正交。
- **證明**：正規方程由 ⟨x − Σcⱼwⱼ, wᵢ⟩ = 0 直接得出；Gram 矩陣在生成集獨立時可逆。義務不僅比對係數，更直接驗證殘差對每個生成向量之內積精確為 0 —— 此為投影性質之獨立見證，與重建路徑無關。∎
- **義務自證**：✔ 通過　（實例數 8）　8 組 Gram 正規方程以多模重建求解，殘差對每個生成向量之內積精確為 0（最佳逼近定理之見證）

#### L-07　最小二乘：連 AᵀA 之組裝都在 𝔽p 上完成

#### L-08　Gram 之 LDLᵀ 多模重建 —— 誠實反例（實測 ×0.6，不應加速）

- **類別**：ℚ 層反例　　**適用空間**：任意 IPSpace（源自 D-01／D-02 Gram–Schmidt）　　**軌道**：精確 ℚ（重建+憑證）
- **定義**：於 𝔽p 上作無開方 Cholesky G = LDLᵀ（L 單位下三角），CRT + 重建後以精確算術驗證 LDLᵀ = G。
- **算式**：G = L D Lᵀ；D_{jj} = ‖q_j‖²；det G = ∏ D_{jj}
- **命題／定理**：定理（正確性）：對稱正定矩陣有唯一 LDLᵀ 分解，且 L 之第 j 行即 Gram–Schmidt 展開係數、D 為正交向量之範數平方。
定理（負面結果，本條之主張）：本路徑永不獲利 —— 實測 ×0.45／×0.56／×0.62（n=6/10/14），比值收斂於約 0.6 而不越過 1。故本條列為反例，不計入加速層。
- **證明**：正確性：對 j 歸納施行無開方 Cholesky，正定性保證 D_{jj} > 0 可除。Gram–Schmidt 之遞迴 q_j = w_j − Σ_{k<j}(⟨w_j,q_k⟩/‖q_k‖²)q_k 與 LDLᵀ 之遞迴逐項對應。義務以函式庫 gram_schmidt 之 ‖q_i‖² 與 det G = ∏Dᵢ 雙重覆核。∎
負面結果之成因：D_j 為前導主子式之比 D_j = Δ_j/Δ_{j−1}（Bareiss 型），其位元數受 Hadamard 界控制而與輸出同階 —— 即「中間量 ≈ 輸出量」，無係數爆炸可消。CRT 之固定開銷（k 個素數之模消去 + 重建）因此永遠無法被攤銷，比值收斂於一常數而非隨 n 發散。此與 L-05 合為「CRT 不適用條件」之二例。∎
- **義務自證**：✔ 通過　（實例數 6）　6 組通過憑證 LDLᵀ = G；對角 D 逐項等於 Gram–Schmidt 正交向量之範數平方，且 det G = ∏Dᵢ

#### L-09　對偶基底與 Riesz 表示之重建

#### N-01　空間表達式之維數／Gram 遞迴與良構性

- **類別**：結構律　　**適用空間**：E ::= Leaf(G) | E⊗E | E⊕E | E*（任意深度之合成樹）　　**軌道**：精確 ℚ

#### N-10　Sylvester–Franke 外冪律 det(Cₖ(A)) = det(A)^C(n−1,k−1)

- **類別**：結構律　　**適用空間**：Λᵏ V（外冪空間）　　**軌道**：精確 ℚ

## 五、加速層實測（K／L／M 群）

1. **語義不變**：環同態 φ_p 與多項式映射交換（推論 Λ1-2），故模路徑算的就是同一個代數量；
2. **提升唯一**：∏p > 2·（Hadamard／係數）界時對稱提升唯一（定理 Λ1-3）、2ND < M 時有理重建唯一（定理 Λ1-5）；
3. **無條件憑證**：C 管以精確算術驗證 Ax = b、AX = I、TA = R、G \| f ∧ G \| g、f(xᵢ) = yᵢ 等，
   憑證通過即正確，與素數個數、重建界、機率假設皆無關 —— 機率只影響效率，不影響正確性。

### 5.3 分派器與正向性定理

**定理 Λ3-13（正向性）**：若判定函數 δ 滿足 δ(params) = true ⇒ cost_fast(params) < cost_base(params)，則「基準 ⊕ δ 分派」之成本逐點 ≤ 基準成本，故分派後之系統必為正向優化。證明：δ 為真時取較小者，為假時取基準，逐點不劣。∎

δ 只看規模參數 (n, b, d) 而不看資料，成本模型之參數（Bareiss 中間量 ≈ 0.6·n·(b+6) 位元、每樞軸一次 Fermat 求逆 46 次乘法、CRT 累積 1.5k²、NTT 3·sz·log sz）皆以實測網格校準，並加 25% 安全邊際（pred_fast·5 < pred_base·4）才切換。目錄 **K-10／L-10／M-08** 於參數網格上逐點實測此蘊含式，無一反例。

### 5.4 三層 CRT 之統一視角

本層之三個群分別對應三種「CRT 同構」，形式完全平行：

| 層 | 同構 | 求值 | 插值／提升 | 群 |
| --- | --- | --- | --- | --- |
| ℤ | ℤ/Mℤ ≅ ∏ ℤ/pᵢℤ | 取餘數 x mod pᵢ | Garner 累進 + 對稱提升 | K |
| ℚ | ℚ ↪ ℤ/Mℤ（分母可逆時） | n·d⁻¹ mod M | 格–歐幾里得有理重建 | L |
| 𝔽[x] | 𝔽[x]/∏(x−aᵢ) ≅ ∏ 𝔽[x]/(x−aᵢ) | 求值 f(aᵢ) | Newton／NTT 逆變換 | M |

三者可任意複合：目錄 M-03（ℤ[x] 乘法）同時用上係數層之 ℤ-CRT 與變數層之 𝔽[x]-CRT；M-04（ℚ[x] 乘法）再疊一層清分母。這正是「不同空間建構互相結合」在計算層面的體現。
